With the above design criteria the strength of the systems are analyzed as follows:

Size of data that can be encrypted before the encryption path is repeated: Assuming each path is capable of encrypting one Hexadecimal:
o 9×109,632 Hexadecimal →9×109,632 x 16 = 1×109,634 bits = 1.8×109,615 Exabyte of information before the path repeats itself (1 Exabyte = 1018 Byte)

In order to compute all possible paths of the map using Brute-Force attack using the most powerful available supercomputer nowadays capable of executing 33.86×1015 Floating-Point Operations Per Second (FLOPS) and assuming a path is calculated per each FLOPS the time needed is as the following:
o 9×109,632 /33.86×1015 = 2.7×109,616 seconds = 8.5×109,608 years, which is computationally unfeasible

Using similar calculation, in order to break the encryption key using Brute-Force attack using the most powerful available supercomputer nowadays assuming a possible key combination is calculated per each FLOPS, the time needed to try all combinations is the following:
o 2×10288 / 33.86×1015 = 6×10271 seconds = 2×10264 years, which is computationally unfeasible

The memory footprint of the design: 32,000 × ((16 × 8) + 16) = 4,608,000 bits = 576Kbyte.
